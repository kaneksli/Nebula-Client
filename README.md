# Nebula VPN — каркас проекта

Рабочий скелет кроссплатформенного VPN/прокси-клиента на Tauri + React + sing-box,
по ТЗ: боковая панель подписок, панель подключения с 3D-глобусом, абстракция
`CoreManager` под движки прокси.

## Что уже работает

- **UI полностью собран и живой** (`npm run dev` открывает рабочий интерфейс
  в браузере на моках, без Rust/Tauri):
  - боковая панель — аккордеон подписок, список серверов с пингом и
    цветовой индикацией, кнопка Auto, контекстное меню удаления, "+"
  - панель подключения — 3D-точечный глобус (Three.js + three-globe),
    облёт камеры к серверу при подключении, акцентный маркер, бейдж
    "Подключено: …", таймер сессии, переключатель TUN/Proxy, статистика
    скорости
  - модалка настроек со всеми разделами из ТЗ (внешний вид, подключение,
    диагностика)
- **Rust-бэкенд**: трейт `CoreManager` (src-tauri/src/core_manager.rs) —
  любой движок (sing-box сейчас, Xray-core потом) реализует один и тот же
  интерфейс `connect/disconnect/stats/measure_ping`. `SingBoxCore`
  (`singbox.rs`) собирает конфиг sing-box, запускает его как дочерний
  процесс, читает статистику через Clash API. Команды Tauri
  (`main.rs`) и системный трей (`tray.rs`) подключены.

## Что оставлено как заглушка — требует отдельной работы

1. **Облако точек суши для глобуса.** `Globe.jsx` теперь использует
   настоящую маску суши/океана (2°-сетка, запакована в base64 прямо в
   файле) вместо случайных точек или эллипсов — континенты узнаваемы, а
   непрозрачное ядро сферы не даёт точкам с обратной стороны (например,
   Австралии) просвечивать сквозь переднюю часть глобуса. Для продакшена
   стоит поднять разрешение маски (сейчас 2°, можно до 0.5–1°) и/или
   перейти на честный GeoJSON суши.
2. **Разбор подписок.** `add_subscription` только создаёт пустую запись.
   Нужен парсер base64-списков `vless://`, `vmess://`, `trojan://`,
   `hysteria2://`, `ss://` и JSON-подписок sing-box/Clash → в
   `ServerConfig.raw_outbound`.
3. **TUN-режим и системные права.** Поднятие TUN-интерфейса требует
   повышенных прав на всех трёх платформах (root/sudo на Linux/macOS,
   админ + драйвер WinTun на Windows). В реальной сборке это должно идти
   через privileged helper-процесс, устанавливаемый инсталлятором, а не
   через sudo-промпт при каждом подключении — это раздел инсталлятора,
   не кода приложения.
4. **Иконки трея/бандла.** `tauri.conf.json` и `tray.rs` ссылаются на
   `icons/*.png|icns|ico`, которых в каркасе нет — добавить реальные
   ассеты перед сборкой.
5. **Таймер/статистика в реальном времени.** Сейчас у Tauri-команды
   `get_stats` нет подписки на фронте — `App.jsx` тикает моковыми
   числами. Нужно: либо периодический `invoke("get_stats")` из React,
   либо (лучше) `app.emit_all` из Rust при каждом обновлении из
   websocket `/traffic` sing-box.
6. **Xray-core как второй движок.** Трейт готов, реализация — нет;
   добавляется как второй `impl CoreManager for XrayCore`.

## Запуск

```bash
npm install
npm run dev          # UI в браузере на моках, без Rust
# или, когда Rust-тулчейн и Tauri CLI настроены:
npm run tauri dev    # полноценное окно с бэкендом
```

Структура:

```
src/                   React-фронтенд
  components/
    Sidebar.jsx         подписки + серверы
    Globe.jsx            3D-глобус (three-globe)
    ConnectionPanel.jsx  кнопка подключения, статы, режим
    Settings.jsx         настройки
src-tauri/
  src/
    core_manager.rs      трейт абстракции движка
    singbox.rs            реализация под sing-box
    tray.rs                системный трей
    main.rs                 команды Tauri, состояние приложения
```
